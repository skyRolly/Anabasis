Anabasis — macOS install / 安装说明
====================================

This bundle is a UNIVERSAL binary (Apple Silicon + Intel).
It is ad-hoc code-signed but NOT notarized by Apple, so macOS Gatekeeper will
quarantine anything extracted from the zip — the manual method below includes
the required de-quarantine step.

本插件为通用二进制(Apple 芯片 + Intel 都可用),做了 ad-hoc 签名但
没有经过 Apple 公证。zip 解压出来的文件会被 macOS 隔离(quarantine),手动安装
时必须按下面步骤去掉隔离,否则 DAW 里加载不出来。

Third-party attribution is NOT inside this package. NOTICE and
THIRD_PARTY_LICENSES.md are published on the release page beside the downloads,
version-named — Anabasis-<version>-NOTICE.txt and
Anabasis-<version>-THIRD_PARTY_LICENSES.md. Download them from there if you need
them, and pass them on with the build if you forward it.
第三方版权声明不在本包内。NOTICE 与 THIRD_PARTY_LICENSES.md 以带版本号的文件名
(Anabasis-<版本>-NOTICE.txt、Anabasis-<版本>-THIRD_PARTY_LICENSES.md)发布在
Release 页面上,与安装包并列;需要时请从那里下载,转发构建时请一并附上。

Both installation methods below install SYSTEM-WIDE (for all users), into
the standard locations:
下面两种安装方式都是系统级安装(对所有用户生效),装到标准位置:

    VST3        ->  /Library/Audio/Plug-Ins/VST3/Anabasis.vst3
    AU          ->  /Library/Audio/Plug-Ins/Components/Anabasis.component
    Standalone  ->  /Applications/Anabasis.app

--------------------------------------------------------------------
A) Installer installation (.pkg, recommended) / 安装程序(.pkg,推荐)
--------------------------------------------------------------------
  Open  Anabasis-<version>-macOS.pkg  (a separate download — it is not inside
  this zip) and follow the installer. The default is a FULL install
  (VST3 + AU + Standalone); click "Customize" on the Installation Type step
  to choose which components to install. Files installed by the package
  carry NO quarantine flag, so none of the Terminal steps below are needed.

  打开 Anabasis-<version>-macOS.pkg(单独下载,不在本 zip 包内)按提示安装。
  默认完整安装(VST3 + AU + 独立版);在"安装类型"一步点"自定义"可以
  选择要安装的组件。用安装包装的文件没有隔离标记,不需要下面的终端命令。

  Because the package is not notarized yet, macOS will refuse the first
  double-click. Open  System Settings > Privacy & Security , scroll down
  and click "Open Anyway" next to the blocked-package message, then
  confirm. (On macOS 14 and earlier you can instead right-click /
  Ctrl-click the .pkg > "Open" > "Open".)
  因为还没有 Apple 公证,第一次打开会被拦。打开"系统设置 > 隐私与安全性",
  在被拦截的提示旁点"仍要打开"并确认。(macOS 14 及更早版本也可以对 .pkg
  右键(按住 Ctrl 点击)选"打开",再点"打开"。)

  Uninstall / 卸载: delete the three installed items listed above (Finder
  asks for your password for the /Library ones).

--------------------------------------------------------------------
B) Manual installation (zip) / 手动安装(zip 包)
--------------------------------------------------------------------
  1) Copy the formats you need / 复制你需要的格式:

     * VST3  (REAPER, Ableton, Cubase, Bitwig, ...):
           sudo mkdir -p /Library/Audio/Plug-Ins/VST3 /Library/Audio/Plug-Ins/Components
           sudo cp -R "Anabasis.vst3"      /Library/Audio/Plug-Ins/VST3/
     * AU / Audio Unit  (Logic Pro, GarageBand, and also REAPER/Ableton):
           sudo cp -R "Anabasis.component" /Library/Audio/Plug-Ins/Components/
     * Standalone / 独立版:
           sudo cp -R "Anabasis.app"       /Applications/

     Logic Pro 和 GarageBand 只认 AU(.component),不认 VST3 —— 用 Logic 的话装 AU。

  2) Remove the quarantine flag / 去掉隔离标记  (REQUIRED / 必须):

           sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/Anabasis.vst3
           sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/Components/Anabasis.component
           sudo xattr -dr com.apple.quarantine /Applications/Anabasis.app

--------------------------------------------------------------------
Rescan in your DAW / 在 DAW 里重新扫描插件
--------------------------------------------------------------------
  * Logic Pro: it runs AU validation on launch. To check from Terminal:
        auval -v aufx Anbs RTec
    (type=aufx, subtype=Anbs, manufacturer=RTec). "PASS" means Logic will see it.
  * REAPER: Preferences > Plug-ins > VST/AU > Re-scan.

--------------------------------------------------------------------
Notes / 说明
--------------------------------------------------------------------
- Two input layouts: mono->stereo and stereo->stereo. On a MONO track the host
  picks the mono->stereo version, which duplicates the single input to both
  channels — the output is always stereo.
- If macOS still complains, right-click the .component/.vst3/.app in Finder
  once and choose "Open", or check System Settings > Privacy & Security for
  an "Open Anyway" button.
- Anabasis.app refuses to open after a manual install? The executable bit can
  be lost in transit (some archive tools drop it). Restore it:
  Anabasis.app 打不开时,可能是解压丢了可执行权限,执行:
      sudo chmod +x /Applications/Anabasis.app/Contents/MacOS/Anabasis
