# JUCE 9.0.1 → 9.0.4 upgrade (ADR-0047)

Requested 2026-10-21: safely upgrade Anabasis to JUCE 9.0.4, fix resulting issues, synchronize
documentation and create a PR. Application version remains **0.2.17**; no tag/release is created.
First-party baseline: **`a3a8785888fedc3a7b6870ce10fba8d896289c15`** (`origin/main`).
Implementation: **`81137d8`**. Anamorph was inspected as a read-only reference and was not modified.

The fifteen consumed modules were derived from the plugin's `JUCE_MODULE_AVAILABLE_*`
definitions, not inferred from this repository's declared link list. All fifteen module
declaration blocks change only their version field: no module requirement moved.

- `juce_dsp`, `juce_audio_processors`, `juce_data_structures`: module version only. In particular,
  `juce_AudioProcessorValueTreeState.cpp` is byte-identical, SHA-256
  `94760f6858acf7fcf52915504cc24702cdea9c031d9a9593919de108884a1ad6`.
- `juce_audio_basics`: MIDI concatenation/UMP changes and a macOS timestamp conversion;
  AudioBuffer, AudioBlock, filters and oversampling implementations are unchanged. Anabasis
  has no MIDI input/output.
- `juce_audio_plugin_client`: AU bus-count synchronization is repaired; Anabasis's fixed
  mono/stereo layout does not add/remove buses. The VST3 source change removes an ARA-only
  destructor; ARA is disabled. AU runtime verification still belongs to macOS.
- `juce_audio_processors_headless`: VST3 hosting lifetime/parameter-notification and shell
  enumeration fixes reach the channel-probe host; LV2 changes do not reach built formats.
- `juce_audio_utils` / devices: MIDI-selector accessibility/API and platform device fixes
  reach JUCE's Standalone configuration surfaces, requiring the existing platform smoke tests.
- `juce_core`: safer malformed String/MemoryBlock/OutputStream handling and XML whitespace
  formatting. XmlDocument and ValueTree serialization are unchanged. The XML writer's
  production diff is formatting of mixed text/elements; Anabasis state is attribute-based.
- events / GUI / OpenGL: message-lock cancellation/recursion, Linux/Windows windowing and
  rendering changes. The lock around component painting remains; native GL behavior is not
  established by a Linux/Xvfb run.
- audio formats / graphics: new default-enabled codecs are excluded explicitly, below.

The intervening `BREAKING_CHANGES.md` entries were walked: no first-party use of the removed
MIDI-selector accessor, ThreadPool callable overloads, SystemStats OS-bitness query,
OpenGLImageType framebuffer accessor or explicit OpenGL image-cache sizing was found.
The libxi development headers are already explicit in both `setup-linux.sh` profiles.
The new Linux `NEEDS_OPENGL_ES` defaults off; desktop OpenGL is retained and the optional
GLES pkg-config probe does not require a new package for this configuration.

`DEPENDENCY_POLICY.md` rule 7 was walked against both source trees. These files are

One existing explanation was wrong at both pins: `showMenuAsync` does not pass
`deleteWhenDismissed=true`. `PopupMenuCompletionCallback` owns the root window in a

register and `PluginEditor.cpp` comment now describe that actual lifetime. No behavior changed.
OpenGL's `CachedImage::renderFrame` still acquires the message-manager try-lock before painting
(`juce_OpenGLContext.cpp:405`); its lifetime still spans `paintComponent`.
JUCE modules still contain no `clang::nonblocking`, `clang::nonallocating` or `__rtsan`
annotations. First-party changes in `src/` refresh comments only.

## Cache regression and codec contract

`set(... CACHE ...)` leaves the old pin in an existing build directory. The guard rejects either
field from Anabasis's previous 9.0.0/9.0.1 defaults before fetching. Both fields must be reset;
custom revisions and the explicit local-checkout path remain supported.

`python3 tests/juce_cache_tests.py`: **6 tests pass**, with subcases for both previous defaults,
one-field resets, mixed pairs, custom/repeated configuration and local old-JUCE comparisons.
The stand-in records the selected pin and deliberately fails at the dependency boundary; no
JUCE download/build is performed. Running the old-cache test against the original
`a3a8785:CMakeLists.txt` fails for **both** previous pins: the original reaches the boundary
with the stale pin. This is the reproduced defect, not a test that passes both implementations.
The Linux CI job runs the regression before normal configuration.

All six plugin/test/tool consumers receive the same list:

```cmake
JUCE_USE_MP3AUDIOFORMAT=0
JUCE_USE_OPUS=0
JUCE_USE_WEBP=0
```

Rejected: silently forcing cache values (overwrites custom revisions), changing defaults alone
(keeps stale builds and adds unused codecs), and accepting the new codec defaults (no consumer
needs them). First-party test-fixture structure was adapted from the read-only Anamorph reference
under ADR-0009; there is no shared module or cross-repository edit.

two self-test suites retain their deliberate non-LTO configuration. All six consumers are

`source /workspace/.onboarding/activate.sh`.

The baseline channel probe hosts the LTO VST3 under Xvfb and runs with
`--assert-discriminating`: **33 scenarios**, **112 pair comparisons**, four declared stereo-link

The cross-version session driver uses the real processor objects from the state target. It

## Reproducing the cross-version session measurement

Save the following two files outside the repository, next to each other. Build the ordinary
`AnabasisStateTests` target at each pin first. The Python helper reuses that target's real
compile/link commands and compiled processor/JUCE objects, replacing only the test entry point.
The paths below are the measured Linux workspace; adjust `/workspace/Anabasis/build` and the
output directory for another checkout. Never combine objects from one pin with headers from
another.

At 9.0.1, compile `session-901`, write `session-901.bin`, then read it twice. Compare the two
read outputs to establish repeatability. At 9.0.4, compile `session-904` and read that same
9.0.1 file. Compare the full read outputs and the original/resaved binary blobs. The driver
sets host rate/buffer details before preparing each render, as a real host does.

`session_probe.cpp`:

```cpp
#include "PluginProcessor.h"
#include <array>
#include <bit>
#include <cmath>
#include <cstdio>
#include <cstdint>

static void describe (AnabasisAudioProcessor& processor)
{
    for (int slot = 0; slot != 2; ++slot)
    {
        processor.switchToSlot (slot);
        std::printf ("slot=%d name=%s dirty=%d\n", slot,
                     processor.currentPresetName().toRawUTF8(), processor.presetDirty());
        for (auto* parameter : processor.getParameters())
            if (auto* ranged = dynamic_cast<juce::RangedAudioParameter*> (parameter))
                std::printf ("%s=%08x\n", ranged->paramID.toRawUTF8(),
                             std::bit_cast<std::uint32_t> (ranged->getValue()));
        for (const double rate : { 44100.0, 48000.0, 96000.0 })
        {
            processor.setNonRealtime (true);
            processor.setRateAndBufferSizeDetails (rate, 256);
            processor.prepareToPlay (rate, 256);
            juce::AudioBuffer<float> audio (2, 256);
            juce::MidiBuffer midi;
            std::uint64_t hash = 14695981039346656037ULL;
            for (int block = 0; block != 150; ++block)
            {
                for (int channel = 0; channel != 2; ++channel)
                    for (int sample = 0; sample != 256; ++sample)
                        audio.setSample (channel, sample,
                            0.4f * (float) std::sin ((double) (block * 256 + sample)
                                                     * (channel == 0 ? 0.03 : 0.047)));
                processor.processBlock (audio, midi);
                for (int channel = 0; channel != 2; ++channel)
                    for (int sample = 0; sample != 256; ++sample)
                        for (unsigned char byte : std::bit_cast<std::array<unsigned char, 4>> (
                                 audio.getSample (channel, sample)))
                            hash = (hash ^ byte) * 1099511628211ULL;
            }
            std::printf ("render %.0f latency=%d hash=%016llx\n", rate,
                         processor.getLatencySamples(), (unsigned long long) hash);
            processor.releaseResources();
        }
    }
}

int main (int argc, char** argv)
{
    if (argc != 3)
        return 2;
    juce::ScopedJuceInitialiser_GUI initialiser;
    const juce::String mode (argv[1]);
    const juce::File file (argv[2]);
    AnabasisAudioProcessor processor;
    juce::MemoryBlock state;
    if (mode == "write")
    {
        processor.applyFactoryPreset (4);
        processor.copySlotToOther();
        processor.switchToSlot (1);
        processor.applyFactoryPreset (8);
        {
            MacroEngine::ScopedRestore restore (processor.getMacroEngine());
            int index = 0;
            for (auto* parameter : processor.getParameters())
                parameter->setValueNotifyingHost ((float) (++index % 11) / 11.0f);
            processor.apvts.getParameter (pid::bypass)->setValueNotifyingHost (0.0f);
            processor.apvts.getParameter (pid::freeze)->setValueNotifyingHost (0.0f);
        }
        auto& internal = processor.internalState.state();
        internal.setProperty (iid::oversample, 2, nullptr);
        internal.setProperty (iid::osPhase, 1, nullptr);
        internal.setProperty (iid::uiScale, 125, nullptr);
        internal.setProperty (iid::ceilingLock, true, nullptr);
        internal.setProperty (iid::tooltipsOn, true, nullptr);
        processor.getStateInformation (state);
        // Exercise XML-special and Unicode metadata through the real reader.
        auto xml = juce::AudioProcessor::getXmlFromBinary (state.getData(), (int) state.getSize());
        auto* slots = xml->getChildByName ("AB");
        for (auto* slot : slots->getChildIterator())
            slot->setAttribute ("presetName", juce::String::fromUTF8 ("升级 & <Recall> \"A/B\""));
        juce::AudioProcessor::copyXmlToBinary (*xml, state);
        processor.setStateInformation (state.getData(), (int) state.getSize());
        processor.getStateInformation (state);
        if (! file.replaceWithData (state.getData(), state.getSize()))
            return 3;
    }
    else if (mode == "read")
    {
        if (! file.loadFileAsData (state))
            return 4;
        processor.setStateInformation (state.getData(), (int) state.getSize());
        juce::MemoryBlock resaved;
        processor.getStateInformation (resaved);
        if (! file.getSiblingFile (file.getFileName() + ".resaved").replaceWithData (
                resaved.getData(), resaved.getSize()))
            return 5;
        std::printf ("resaved-identical=%d size=%zu\n", state == resaved, resaved.getSize());
        if (state != resaved)
            return 6;
    }
    else
        return 7;
    describe (processor);
}
```

`build_session_probe.py`:

```python
from pathlib import Path
import shlex
import subprocess
import sys

build = Path('/workspace/Anabasis/build')
output = Path('/workspace/.juce904-upgrade') / sys.argv[1]
commands = subprocess.check_output(['ninja', '-C', str(build), '-t', 'commands',
                                    'AnabasisStateTests'], text=True).splitlines()
source = next(c for c in commands if ' -c /workspace/Anabasis/tests/state_tests.cpp' in c)
args = shlex.split(source)
args[args.index('-o') + 1] = str(output) + '.o'
args[args.index('-c') + 1] = '/workspace/.juce904-upgrade/session_probe.cpp'
if '-MF' in args:
    args[args.index('-MF') + 1] = str(output) + '.d'
subprocess.run(args, cwd=build, check=True)
link = shlex.split(commands[-1])
link = link[link.index('&&') + 1:]
link = link[:link.index('&&')]
link = [str(output) + '.o' if a.endswith('/tests/state_tests.cpp.o') else a for a in link]
link = [a for a in link if not a.startswith('-Wl,--dependency-file=')]
link[link.index('-o') + 1] = str(output)
subprocess.run(link, cwd=build, check=True)
```
