## 2. Current dependency, targets and support

`CMakeLists.txt` requires CMake ≥3.22/C++23, pins the two cache fields, uses FetchContent with
`GIT_SHALLOW TRUE`, or `add_subdirectory` for `ANABASIS_JUCE_PATH`. Its guard refuses either
9.0.0/9.0.1 default field while preserving custom revisions and explicit local comparisons.
It does not refuse current 9.0.4. A defaults-only target bump would therefore retain the old
cache silently. Proposed change extends the existing guard/diagnostic and six regression tests
to 9.0.4 as well as the historical defaults; no forced cache assignment or mutable tag.

The shared codec list explicitly defines `JUCE_USE_MP3AUDIOFORMAT=0`, `JUCE_USE_OPUS=0`,
`JUCE_USE_WEBP=0`. All six `target_compile_definitions` consumers include it: Anabasis,
AnabasisTests, AnabasisStateTests, AnabasisBench, AnabasisChannelProbe, AnabasisEngineRepro.
The plugin's PUBLIC definitions propagate to generated format targets by its existing JUCE
model. Actual generated compile commands/objects remain to be verified after a successful
configuration. FLAC/Ogg/Vorbis remain as before; no other definition or dependency changes.

Support remains Linux x86-64 and Windows x64 VST3/Standalone, macOS universal arm64+x86_64
VST3/AU/Standalone, and native Intel validation with Standalone disabled. Preserve macOS Intel
10.13/arm64 11.0 floors, Linux ABI policy, Clang 22 shipping and GCC 16 compatibility toolchains,
LTO distinction and all existing compiler settings. Input remains mono/stereo to stereo;
unsupported layouts/formats/platforms are not added.

### Dependency-internals register, re-walked

`94760f6858acf7fcf52915504cc24702cdea9c031d9a9593919de108884a1ad6`.

attachment implementations do not change. Component insertion order and `isMouseOver` reasoning
remain. `ParameterAdapter` retains default `seq_cst` atomic publication; no new first-party
thread, ordering or adoption path is introduced by this proposal.

The PopupMenu parented branch still binds the default look-and-feel before adding the child,
so `presetMenusOpen` remains the count owner for preset menus. `preparePopupMenuWindow` moves
515 → 511. Child append ordering preserves the menu above the raised shield; root/submenu modal
entry remains and completion still owns/deletes the menu. Parented menu opacity now differs on
desktops without transparent peers. Native menu/tooltip/slider-popup windows gain an associated
component, and pointer dispatch retargets surviving ancestors when a recipient is deleted.
These changes require native shield/hover/teardown checks; they are not a reason to rewrite the
shield or infer callback safety from a compile.

`juce_OpenGLContext.cpp:405` still takes the render-frame message try-lock whose scope includes
component painting. The Anabasis atomic display/bookkeeping contracts therefore remain needed.
No first-party use was found of removed NativeMessageBox names, old `withButton` signature,
`createAlertWindow`, `createNewPeer` or virtual `addToDesktop`. Refresh live JUCE coordinates
when implementation occurs; retain coordinates in historical ADRs/worklogs.

## 4. Build requirements and licensing provenance

JUCE still requires CMake ≥3.22. No new desktop dependency/package declaration was found.
Windows resource generation moves to configure time; `Spatial;Fx` category ordering is special-
cased, while Anabasis's `Fx/Dynamics/Mastering` categories are unaffected. Native VERSIONINFO,
installer, icon, metadata and symbol checks remain required. Projucer macOS/iOS default floors
and Android Gradle/Java/NDK changes do not control this CMake project. Xcode 27's minimum-target
restriction could conflict with the retained older macOS floor; an actual conflict must be
escalated instead of raising that floor or changing toolchains inside this upgrade.

JUCE-owned metadata. No new package or changed licence expression was found. The exact recorded
scan compares 47 named licence/copyright/notice/readme files, including root `LICENSE.md` and
the selected files under `modules/`, with no changed/add/remove result in that selection. It is not a claim to have
compared every source header or to reuse a sibling's object-code audit.

Read target HarfBuzz `COPYING` (Old MIT) and its attribution/disclaimer terms; existing
LunaSVG/PlutoVG, transitive FreeType FTL/stb grants, Steinberg/AU SDK, image/zlib, FLAC/Ogg/Vorbis
and OpenGL notices retain their texts. New HarfBuzz source paths do not add a new package/grant
in the reviewed inventory. MP3/Opus/WebP trees/exclusions stay unchanged. Final objects and
